# 유소민의 역할과 기여

유소민은 결혼·출산 준비 헬스케어 프로젝트의 프론트엔드 개발과 인증·백엔드 API 연동을 담당했다. 건강 설문·결과 리포트·생활 미션·커뮤니티를 한 흐름으로 연결하고 상태 복구와 배포 경로 오류를 개선했다.

2026-11-11 기준으로 기존 역할 소개, 저장소 파일·커밋과 관련 Codex 채팅을 대조했다. 개발·조사·문서화에는 Codex·Claude 등 AI 도구를 활용했으며, 팀 공동 작업과 본인의 담당 범위를 구분했다.

## 검증 범위와 협업

이 저장소는 프론트엔드이며 별도 백엔드의 구현을 본인 기여로 포함하지 않는다. 빌드 성공과 실제 로그인·서버 저장 성공을 구분한다. 기존 README의 린트 오류 16개·경고 1개와 테스트 스크립트 부재를 유지하며 이번 문서 작성으로 해결됐다고 표시하지 않는다.

이번 변경은 역할 문서 정리다. 앱 테스트·실계정 연동·배포·대회 제출을 새로 수행한 결과로 표시하지 않는다. 채팅 원문과 계정 비밀값은 저장소에 옮기지 않았다.
