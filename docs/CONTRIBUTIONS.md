# 담당 역할과 주요 작업

건강 설문·결과 리포트·생활 미션·커뮤니티의 프론트엔드를 개발하고, 이메일·카카오 인증과 백엔드 API를 연동했다.

## 주요 작업

| 영역 | 수행 내용 | 관련 코드·문서 |
|---|---|---|
| 화면·사용 흐름 | 온보딩, 홈 요약, 검사 설문·기록·리포트, 미션·꽃 성장·커뮤니티 화면을 구현·개선했다. | [src/pages](../src/pages) |
| 인증·API | 이메일·카카오 인증, 사용자 표시명, 결과·미션 API와 서버 계약을 맞췄다. | [src/lib/auth.ts](../src/lib/auth.ts) |
| 상태 복구 | 검사 세션 복구와 토큰 만료 시 로그아웃·로그인 이동을 정리해 화면 반복 전환을 개선했다. | [src/store/useTestSessionStore.ts](../src/store/useTestSessionStore.ts) |
| 커뮤니티·배포 | 게시글 저장·신고·차단 UX와 Netlify API 프록시·SPA/OAuth 콜백 경로를 보완했다. | [netlify.toml](../netlify.toml) |

## 개발 범위

이 저장소의 개발 범위는 프론트엔드다. 인증·검사 저장·결과 조회는 별도 백엔드에 연결한다.
